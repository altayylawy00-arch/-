# One-Click Language — Windows Demo

نسخة Windows تجريبية من المشروع.

## ماذا تفعل؟

- **Caps Lock** يبدّل لغة لوحة المفاتيح بسرعة بين اللغات المثبتة في Windows.
- شريط صغير عائم يحتوي على:
  - **AR ⇄ EN** — تبديل لغة الكيبورد.
  - **Translate** — حدّد نصاً في أي برنامج واضغط الزر؛ يفتح Google Translate والنص موجود تلقائياً.
  - **Quick Fix** — يصلّح المسافات وعلامات الترقيم للنص المحدد ويستبدله مباشرة.
  - **Typing Settings** — يفتح إعدادات الكتابة في Windows لتفعيل التصحيح التلقائي والاقتراحات.

## التشغيل

1. ثبّت **AutoHotkey v2**.
2. افتح الملف:
   `one-click-language.ahk`
3. ستظهر نافذة صغيرة أعلى الشاشة.
4. اضغط **Caps Lock** لتبديل اللغة.

## ملاحظات

- يجب أن تكون العربية والإنجليزية مضافتين إلى Windows.
- زر **Translate** لا يحتاج منك Copy/Paste؛ الأداة تنسخ النص المحدد مؤقتاً وتفتح الترجمة تلقائياً.
- **Quick Fix** حالياً يصلح التنسيق والمسافات وعلامات الترقيم، وليس تدقيقاً لغوياً ذكياً كاملاً.
- النسخة القادمة يمكن ربطها بخدمة ترجمة/تصحيح API لإرجاع النص المترجم أو المصحح مباشرة داخل نفس المكان.
