# One-Click Language — Windows Demo

نسخة Windows محسّنة من المشروع.

## ماذا تفعل الآن؟

- Caps Lock يبدّل لغة لوحة المفاتيح بسرعة بين اللغات المثبتة في Windows.
- شريط صغير عائم يحتوي على:
  - AR ⇄ EN — تبديل لغة الكيبورد.
  - Translate — حدّد نصاً في أي برنامج واضغط الزر؛ يتم ترجمته عربي ⇄ إنكليزي ويُستبدل النص مباشرة.
  - Smart Fix — حدّد النص واضغط الزر؛ يتم فحص الإملاء والقواعد ثم يُستبدل النص بالنسخة المصححة.
  - Typing Settings — يفتح إعدادات الكتابة في Windows.
- تم إصلاح مشكلة فقدان تحديد النص عند الضغط على أزرار الشريط.

## الملفات المطلوبة

ضع هذين الملفين في نفس المجلد:
- one-click-language.ahk
- language-helper.ps1

## التشغيل

1. ثبّت AutoHotkey v2.
2. نزّل الملفين الموجودين داخل مجلد windows.
3. ضع الملفين في نفس المجلد على جهازك.
4. افتح one-click-language.ahk.
5. ستظهر نافذة صغيرة أعلى الشاشة.
6. جرّب:
   - ظلّل نصاً عربيًا ثم اضغط Translate → يتحول للإنكليزي داخل نفس المكان.
   - ظلّل نصاً إنكليزيًا ثم اضغط Translate → يتحول للعربي.
   - ظلّل نصاً فيه أخطاء ثم اضغط Smart Fix.

## ملاحظات مهمة

- الترجمة تحتاج اتصالاً بالإنترنت.
- الترجمة تستخدم endpoint ويب خفيف من Google Translate بدون API Key؛ هو عملي للتجربة لكنه ليس Google Cloud Translation API الرسمي.
- Smart Fix يستخدم LanguageTool. دعمه للإنكليزية أقوى، ودعم العربية موجود لكنه جزئي.
- إذا كان النص داخل برنامج يمنع النسخ/اللصق أو يغيّر التحديد عند فقدان التركيز، قد لا يعمل الاستبدال في ذلك البرنامج.
- لا يتم إرسال النص إلى OpenAI في هذه النسخة.
