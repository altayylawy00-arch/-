# One-Click Language Demo

مشروع تجريبي بسيط لاختبار GitHub من خلال ChatGPT.

## الفكرة
أداة ويب صغيرة تساعد على:
- التبديل السريع بين العربية والإنجليزية داخل الواجهة.
- اكتشاف اتجاه النص تلقائياً.
- تفعيل التدقيق الإملائي المدمج في المتصفح.
- تصحيح بعض المسافات وعلامات الترقيم بشكل سريع.
- تجهيز النص للترجمة بضغطة واحدة.

> هذه نسخة تجريبية للتعلم وتجربة GitHub، وليست أداة ترجمة إنتاجية نهائية.
